# .github

This is a [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization)
repository for the `kurkle` account. GitHub uses the files here — `CONTRIBUTING.md`,
`CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, and the issue templates in
`.github/ISSUE_TEMPLATE/` — as the fallback for every other public repository on this
account that doesn't define its own copy of that file.

`profile/README.md` is a separate, unrelated GitHub feature: it renders as the profile
page at [github.com/kurkle](https://github.com/kurkle).

**None of these files show up in the file tree of the repositories that use them.**
They apply silently — if you're looking at, say, `chartjs-chart-matrix` and wondering
why it has a "Security policy" or an issue template despite no such file in its own
tree, this repository is why.

Not shared this way: license files (GitHub doesn't support a default `LICENSE`) and
`.github/dependabot.yml` (not a supported default file type either) — both stay
repository-specific.
