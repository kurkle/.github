# Support

## Have a question about how to use Chart.js itself?

If your question is about Chart.js core — general chart configuration, scales,
options that aren't specific to this chart type or plugin — please ask in
[Chart.js's own discussions](https://github.com/chartjs/Chart.js/discussions) or check
its [documentation](https://www.chartjs.org/docs/latest/). Questions like this filed
against a plugin or chart-type repository usually sit unanswered longer than they
would on Chart.js's own channels, simply because they're in the wrong place.

## Found a bug?

Please [open an issue](../../issues/new/choose) using the bug report template. If this
repository has a documentation site, its samples are editable directly in the browser
— reproducing the problem there and pasting the resulting code is the fastest way to
get it fixed. See [CONTRIBUTING.md](CONTRIBUTING.md) for details.

## Have a feature idea?

Please [open an issue](../../issues/new/choose) using the feature request template.

## Found a security vulnerability?

Please don't open a public issue — see [SECURITY.md](SECURITY.md) instead.
